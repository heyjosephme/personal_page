# 我使用的工具
记录支撑日常工作的工具、软件和硬件，并持续更新。

## 💻 编辑器与终端
**Claude Code（主力）**
- 使用 AI CLI 生成代码和重构
- 配合 LazyVim 审查和调整生成的代码

**Neovim + LazyVim（审查与编辑）**
- 使用 LazyVim 的默认配置与插件管理
- 用于审查 AI 生成的代码、快速编辑和远程工作

**终端**
- Ghostty（现代 GPU 加速终端）
- Zsh + Oh My Zsh
- tmux 管理会话

## 🛠️ 开发工具
**版本控制**
- Git + GitHub（更喜欢 `gh` CLI，而非网页界面）
- 以命令行为主的工作流

**API 开发**
- 使用 Postman 进行复杂 API 测试
- 使用 HTTPie 快速发送 CLI 请求

**容器与部署**
- Docker + Colima（轻量级 Docker 运行时）
- Kamal 部署 Rails 应用
- 本站使用 Cloudflare Workers

**数据库**
- 多数项目使用 SQLite3
- 主要使用 CLI，不用 GUI 工具

## 🖥️ 硬件
**主力电脑**
- MacBook Air/Pro（个人与工作）
- 极简配置：只用笔记本电脑

没有花哨的外设，也没有复杂的桌面布置，保持简单便携。

## 📝 效率工具
**笔记（按偏好排序）**
- Obsidian → Markdown 文件 → Notion → Apple Notes
- 重视纯文本与可迁移性

**任务管理**
- 使用 `todo.md` 管理个人任务
- 使用 GitHub Issues 处理代码相关工作
- 协作时使用 GitHub Projects 和 Notion

**沟通**
- 工作使用 Slack
- 开发者社区使用 Discord

**浏览器**
- 注重隐私，以 Brave 为主
- Firefox 作为备用

## 🌐 本站
**技术栈**
- 框架：Astro 7（Cloudflare Workers SSR）
- UI：React 19 + TailwindCSS 4
- 组件：shadcn/ui
- 样式：Tailwind 与自定义设计系统
- 图标：Lucide React + Remix Icons
- 动画：Framer Motion
- 代码检查：Biome
- 部署：Cloudflare Workers 与静态资源

**内容**
- 带 frontmatter 的 Markdown
- 类型安全的内容集合
- 阅读时间计算
